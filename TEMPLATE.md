# Template provenance

Adapted from [Tabler](https://github.com/tabler/tabler), the MIT-licensed Bootstrap dashboard template, version 1.5.1, upstream commit 0ff4043ba699bbc23639421147953481019caaf1. The vertical dashboard layout and bundled Tabler component stylesheet are the template foundation; navigation, application logic, content, persistence and custom visual treatment are new.

Upstream had 41,667 GitHub stars and was not archived when checked September 10, 2026. Popularity supports the template choice; this app has its own validation. No upstream endorsement is implied.
